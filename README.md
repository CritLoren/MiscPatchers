# Current patchers:

## VR Eye Adaptation Fix
Tries to fix Skyrim VR eye adaptation by setting cinematic contrast to 1. Based on [findings](https://www.nexusmods.com/skyrimspecialedition/mods/109397) from SaltyMeatBoy.

## Smart Disenchant Everything
Tries to remove the flag that disables disenchanting from items in a smart way, by not removing it from items that have their enchantments expecting for specific items, or where the enchantment is likely a dummy enchantment and the logic is actually in a script, making disenchanting useless.
